PART 01روش حل مسئله در لایو کدینگ

در لایو کدینگ، مصاحبه‌گر بیشتر از «جواب نهایی» به روش فکر کردن تو نگاه می‌کند. یک راه‌حل ساده که درست کار می‌کند و خوب توضیح داده شده، از یک راه‌حل «باهوشانه» که نیمه‌کاره مانده خیلی بهتر است.

1.1مصاحبه‌گر به چه چیزهایی نمره می‌دهد؟

معیاریعنی چه؟

1.2روش 6 مرحله‌ای (همیشه همین را انجام بده)

  1. بفهم و بپرس (Clarify) — 1 تا 2 دقیقه. ورودی دقیقاً چیست؟ خروجی چه شکلی است؟ لیست خالی؟ عدد منفی؟ حروف بزرگ و کوچک؟ اگر چیزی مبهم است، یک فرض منطقی بکن و بلند بگو.
  2. مثال بزن (Examples). یک مثال عادی و یک مثال مرزی را به شکل کامنت یا assert بنویس. این کار هم فهمت را نشان می‌دهد، هم بعداً تستت می‌شود.
  3. اول ایده‌ی ساده (Plan). با زبان ساده بگو چه می‌خواهی بکنی. اگر راه بهینه به ذهنت نمی‌رسد، با راه ساده (brute force) شروع کن و بگو بعداً بهترش می‌کنی.
  4. کد بزن (Code). یک تابع با اسم خوب بنویس و حین نوشتن توضیح بده. منطق اضافه را در یک تابع کمکی (helper function) بگذار.
  5. تست کن (Test). کد را با مثال‌هایت اجرا کن. حالت‌های مرزی را چک کن: ورودی خالی، یک عضو، مقادیر تکراری، None.
  6. پیچیدگی و بهبود (Big-O & Optimize). پیچیدگی زمانی و حافظه را بگو. اگر وقت ماند، بهترش کن یا بگو چطور بهترش می‌کردی.

1.4یک مثال کامل با «بلند فکر کردن»

Task: Given a list of trips as (driver, km), return the n longest trips, longest first.
  • Clarify: «اگر دو سفر طول برابر داشتند چه؟ اگر لیست کمتر از n عضو داشت؟» ← فرض: ترتیب اولیه‌ی سفرهای برابر حفظ شود؛ اگر کمتر بود، همه را برگردان.
  • Example: ورودی [("Ali", 12.5), ("Sara", 40.0), ("Mia", 7.2), ("Tom", 40.0)] با n=2 ← خروجی Sara و بعد Tom.
  • Plan: «بر اساس km نزولی مرتب می‌کنم و n تای اول را برمی‌دارم.»
  • Code + Test:
def top_n_trips(trips, n=3):
    """Return the n longest trips as (driver, km), longest first."""
    if n <= 0:
        return []
    return sorted(trips, key=lambda t: t[1], reverse=True)[:n]

trips = [("Ali", 12.5), ("Sara", 40.0), ("Mia", 7.2), ("Tom", 40.0)]
assert top_n_trips(trips, 2) == [("Sara", 40.0), ("Tom", 40.0)]
assert top_n_trips([], 3) == []
assert top_n_trips(trips, 0) == []
print(top_n_trips(trips))
Output
[('Sara', 40.0), ('Tom', 40.0), ('Ali', 12.5)]

"Sorting is O(n log n). Python's sort is stable, so trips with the same distance keep their original order. If the list were very long and I needed only a few trips, heapq.nlargest would give O(N log n) instead of O(N log N)."

def is_palindrome(s: str) -> bool:
    cleaned = [ch.lower() for ch in s if ch.isalnum()]
    return cleaned == cleaned[::-1]

def is_palindrome_two_pointers(s: str) -> bool:
    left, right = 0, len(s) - 1
    while left < right:
        if not s[left].isalnum():
            left += 1
        elif not s[right].isalnum():
            right -= 1
        elif s[left].lower() != s[right].lower():
            return False
        else:
            left += 1
            right -= 1
    return True

def is_anagram(a: str, b: str) -> bool:

    b = b.replace(" ", "").lower()

    for w in words:

    return list(groups.values())

    counts = {}

        w = w.strip(".,!?;:\"'()")
        if w:
            counts[w] = counts.get(w, 0) + 1
    # sort by count (high first), then alphabetically for ties
    return sorted(counts.items(), key=lambda kv: (-kv[1], kv[0]))[:k]

P09فشرده‌سازی رشتهRun-length encodingO(n)

from itertools import groupby

def compress(s: str) -> str:
    if not s:
        return ""
    result = []
    current, count = s[0], 1
    for ch in s[1:]:
        if ch == current:
            count += 1
        else:
            result.append(f"{current}{count}")
            current, count = ch, 1
    result.append(f"{current}{count}")       # don't forget the last group
    return "".join(result)

def compress_groupby(s: str) -> str:
    return "".join(f"{ch}{len(list(g))}" for ch, g in groupby(s))

def is_balanced(s: str) -> bool:
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = []
    for ch in s:
        if ch in "([{":
            stack.append(ch)
        elif ch in pairs:
            if not stack or stack.pop() != pairs[ch]:
                return False
    return not stack                         # leftovers -> not balanced

def is_prime(n: int) -> bool:
    if n < 2:
        return False
    i = 2
    while i * i <= n:                        # only up to sqrt(n)
        if n % i == 0:
            return False
        i += 1
    return True

def primes_up_to(n: int) -> list[int]:
    """Sieve of Eratosthenes."""
    if n < 2:
        return []
    is_p = [True] * (n + 1)
    is_p[0] = is_p[1] = False
    for i in range(2, int(n ** 0.5) + 1):
        if is_p[i]:
            for j in range(i * i, n + 1, i):
                is_p[j] = False
    return [i for i, p in enumerate(is_p) if p]

def two_sum_brute(nums, target):             # O(n^2)
    for i in range(len(nums)):
        for j in range(i + 1, len(nums)):
            if nums[i] + nums[j] == target:
                return i, j
    return None

def two_sum(nums, target):                   # O(n) with a dict
    seen = {}                                # value -> index
    for i, n in enumerate(nums):
        need = target - n
        if need in seen:
            return seen[need], i
        seen[n] = i
    return None

def moving_average(values, window):
    if window <= 0 or window > len(values):
        raise ValueError("invalid window")
    window_sum = sum(values[:window])
    result = [window_sum / window]
    for i in range(window, len(values)):
        window_sum += values[i] - values[i - window]   # slide the window
        result.append(window_sum / window)
    return result

    return -1

def bubble_sort(nums):
    nums = nums[:]                           # don't modify the input
    n = len(nums)
    for i in range(n):
        swapped = False
        for j in range(n - 1 - i):
            if nums[j] > nums[j + 1]:
                nums[j], nums[j + 1] = nums[j + 1], nums[j]
                swapped = True
        if not swapped:                      # already sorted -> stop
            break
    return nums

M1ردیاب تسک‌های پروژهTask tracker classOOP + dict

Write a TaskTracker class with: add(title, owner, hours, due) — reject duplicate titles and non-positive hours; complete(title); overdue(today) — open tasks past their due date, oldest first; workload() — open hours per owner, highest first.
from dataclasses import dataclass
from datetime import date

@dataclass
class Task:
    title: str
    owner: str
    hours: float
    due: date
    done: bool = False

class TaskTracker:
    def __init__(self):
        self._tasks = {}                     # title -> Task

    def add(self, title, owner, hours, due):
        if title in self._tasks:
            raise ValueError(f"task {title!r} already exists")
        if hours <= 0:
            raise ValueError("hours must be positive")
        self._tasks[title] = Task(title, owner, hours, due)

    def complete(self, title):
        if title not in self._tasks:
            raise KeyError(f"unknown task {title!r}")
        self._tasks[title].done = True

    def open_tasks(self):
        return [t for t in self._tasks.values() if not t.done]

    def overdue(self, today):
        late = [t for t in self.open_tasks() if t.due < today]
        return sorted(late, key=lambda t: t.due)

    def workload(self):
        load = {}
        for t in self.open_tasks():
            load[t.owner] = load.get(t.owner, 0) + t.hours
        return dict(sorted(load.items(), key=lambda kv: -kv[1]))

M3ادغام جلسه‌های هم‌پوشانMerge overlapping meetingsO(n log n)

Given meetings as ("HH:MM", "HH:MM") pairs in any order, return the merged busy blocks of the day.
def to_minutes(t):
    h, m = map(int, t.split(":"))
    return h * 60 + m

def to_hhmm(minutes):
    return f"{minutes // 60:02d}:{minutes % 60:02d}"

def merge_meetings(meetings):
    """[('09:00', '10:00'), ...] -> merged busy blocks."""
    intervals = sorted((to_minutes(s), to_minutes(e)) for s, e in meetings)
    merged = []
    for start, end in intervals:
        if merged and start <= merged[-1][1]:        # overlaps last block
            merged[-1][1] = max(merged[-1][1], end)
        else:
            merged.append([start, end])
    return [(to_hhmm(s), to_hhmm(e)) for s, e in merged]

meetings = [("09:00", "10:00"), ("09:30", "11:00"),
            ("13:00", "13:30"), ("11:00", "11:15")]
print(merge_meetings(meetings))

from datetime import datetime

FMT = "%Y-%m-%d %H:%M"

def charging_cost(start, end, kwh, price_per_kwh=0.59,
                  fee_per_min=0.10, free_minutes=240):
    """Energy cost + blocking fee after free_minutes."""
    minutes = (datetime.strptime(end, FMT)
               - datetime.strptime(start, FMT)).total_seconds() / 60
    if minutes < 0 or kwh < 0:
        raise ValueError("invalid session")
    blocking = max(0, minutes - free_minutes) * fee_per_min
    return round(kwh * price_per_kwh + blocking, 2)
